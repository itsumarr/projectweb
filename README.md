## Адаптивность

Адаптивность выполнена для следующих устройств:

| Устройство | Ширина экрана |
|------------|---------------|
| Смартфоны | до 576px |
| Планшеты | 577px - 992px |
| Десктопы | от 993px |

### Контрольные точки (breakpoints):
- `max-width: 992px` - планшеты
- `max-width: 576px` - смартфоны  
- `max-width: 375px` - маленькие смартфоны

### Изменения на мобильных устройствах:
- Скрыто меню навигации в шапке
- Уменьшены шрифты и отступы
- Карточки товаров расположены в колонку
- Сетка из 3 колонок превращается в 1 колонку
- Футер перестроен в вертикальный блок
