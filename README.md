## Адаптивность

Адаптивность выполнена по инструкции для следующих устройств:

| Устройство | Ширина экрана |
|------------|---------------|
| Смартфоны | до 576px |

### Контрольные точки (breakpoints):
- `max-width: 576px` - мобильные устройства

### Изменения на мобильных устройствах (до 576px):
- ✅ Главное меню в шапке скрыто (`display: none`)
- ✅ У кнопок в шапке оставлены только иконки
- ✅ Уменьшены шрифты (использованы rem/em)
- ✅ Уменьшены отступы (padding, margin)
- ✅ Сетка из 3 колонок превращается в 1 колонку
- ✅ Футер перестроен в вертикальный блок
- ✅ Изображения не выходят за границы карточек
